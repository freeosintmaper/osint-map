# Резервное копирование «Карты автора»

Авторские полигоны хранятся в таблице Supabase `control_zones`. Этот механизм добавляет независимую копию в GitHub и запасной способ отображения слоя.

## Что делает автоматизация

- Каждый день в 04:23 UTC GitHub Actions читает таблицу `control_zones` через публичный Supabase anon key, который уже используется фронтендом.
- Запрос выполняется только на чтение через публичный REST API Supabase и подчиняется RLS-политикам проекта. Секрет с правами записи или администрирования не используется.
- Данные проверяются: обязательные поля, уникальные ID, типы геометрии, диапазоны координат и замкнутость колец GeoJSON.
- Последняя версия сохраняется в `data/author-zones.geojson`.
- При изменении данных создаётся отдельная неизменяемая версия в `data/author-zones-history/`. Если данные не изменились, лишний коммит не создаётся.
- Пустой, повреждённый или недоступный ответ Supabase приводит к ошибке workflow. Существующая резервная копия не перезаписывается.
- Workflow можно запустить вручную через GitHub Actions → **Backup author zones** → **Run workflow**.

## Как карта использует копию

При загрузке карта сначала обращается к Supabase. Если Supabase недоступен после повторных попыток, используется локальный кэш браузера. Если кэша на устройстве нет, карта пытается загрузить `data/author-zones.geojson` из опубликованного репозитория.

Резервная копия предназначена для восстановления и чтения. Она не синхронизирует изменения обратно в Supabase автоматически и не заменяет основную базу данных. Это сознательная защита от перезаписи: автоматическая процедура не должна самостоятельно изменять авторские территории.

## Первый запуск

После добавления workflow запустите его вручную один раз. Успешный запуск создаст первую копию. Для работы используется тот же публичный доступ Supabase, что и у карты. Если таблица не разрешает публичное чтение, workflow завершится ошибкой и сохранит прежнюю копию; в таком случае необходимо отдельно настроить безопасную политику чтения, а не добавлять service-role key в репозиторий.

## Восстановление

1. Откройте `data/author-zones-history/` и выберите GeoJSON-снимок.
2. Для просмотра загрузите файл в любой совместимый GeoJSON-инструмент.
3. Перед восстановлением в Supabase сделайте отдельную резервную копию текущей таблицы и восстановите данные только через авторизованный административный доступ.

Исторические снимки публичны, как и сам публичный слой карты. Не помещайте в этот слой приватные заметки, персональные данные или чувствительную информацию.
