# Настройка ИИ-помощника зон

Интерфейс ИИ-помощника находится в редакторе «Карта автора». Функция создаёт черновики изменений зон и возвращает их в браузер для проверки. **Она не записывает зоны в базу самостоятельно**: каждое предложение пользователь применяет отдельной кнопкой.

## Что потребуется

- Доступ администратора к проекту Supabase, который использует карта: `zojqbhnwsycqhaiqpgxh`.
- Аккаунт Google AI Studio и API-ключ Gemini.
- Email администратора, которым выполняется вход в админ-панель карты.

API-ключ Gemini хранится только в секретах Supabase Edge Function. Не вставляйте его в `index.html`, GitHub Pages или коммиты.

## Развёртывание

В терминале с установленным Supabase CLI выполните:

```bash
supabase login
supabase link --project-ref zojqbhnwsycqhaiqpgxh
supabase secrets set GEMINI_API_KEY="ВАШ_GEMINI_API_KEY" ZONE_AI_ALLOWED_EMAILS="admin@example.com" GEMINI_MODEL="gemini-3.8-flash"
supabase functions deploy zone-assistant
```

Замените `ВАШ_GEMINI_API_KEY` и `admin@example.com` своими значениями. Если у администратора несколько разрешённых адресов, перечислите их через запятую в `ZONE_AI_ALLOWED_EMAILS`.

Функция проверяет Supabase-сессию и email из allow-list перед вызовом Gemini. Она не использует service-role key и не выполняет операции записи в `control_zones`. Сохранение проходит из браузера через текущие Supabase RLS-политики.

Если модель недоступна для вашего API-проекта, задайте в `GEMINI_MODEL` название модели, поддерживаемой вашим Gemini API. Справочник: https://ai.google.dev/api/generate-content

## Проверка

1. Откройте сайт и войдите через кнопку администратора.
2. Откройте «Карта автора» → «ИИ-помощник зон».
3. Введите команду с явными координатами, например: «Создай серую зону вокруг координат 50.4501, 30.5234 радиусом примерно 5 км».
4. Проверьте пунктирный контур и причину предложения на карте.
5. Нажмите «Применить предложение» только после проверки.

Кнопка автоматического анализа использует события за последние 48 часов. Точки ударов, тревог и политические сообщения сами по себе не доказывают изменение контроля территории; функция специально просит модель не выводить границы только из таких точек. Любое предложение нужно сверять с первоисточниками.

Если ИИ не настроен, интерфейс покажет ошибку настройки вместо того, чтобы менять зоны без подтверждения.
