# Журнал изменений

Все даты указаны по UTC. Журнал описывает изменения проекта, а не подтверждает истинность отдельных сообщений.

## 2026-10-27 — Прозрачность источников и открытые данные

- Добавлена страница методологии с описанием источников, фильтрации, порогов населения, смещения координат и ограничений LLM.
- В карточках событий показаны канал-источник, классификация стороны источника и отметка «Не проверено».
- События с каналами, классифицированными как UA и RU, визуально выделяются для приоритетной проверки. Это сигнал, а не доказательство независимого подтверждения.
- Добавлен экспорт метаданных событий в GeoJSON с координатами, ссылками на первоисточники, статусом проверки и лицензионными оговорками.
- Добавлена страница исправлений и форма GitHub Issue для сообщений об ошибках.
- Добавлены ссылки на новые страницы в README.
